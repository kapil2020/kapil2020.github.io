The DRUM Web App is a decision-support tool designed to evaluate demand responsive mobility services for urban transport agencies. Built with a Python backend and a modern web interface, the tool allows planners to simulate flexible route bus services, estimate potential demand, and assess service performance. It integrates GIS data, trip patterns, and optimisation algorithms to recommend routes and schedules that respond dynamically to rider requests. The project was developed at IIT Kharagpur as part of my doctoral research, and the app aims to help cities deliver more efficient and inclusive public transit.
